# 🚀 Deploy Your Store Permanently

## Option 1: GitHub Pages (FREE - Recommended)

### Step 1: Create GitHub Account
1. Go to https://github.com
2. Sign up for free account

### Step 2: Create New Repository
1. Click "New repository"
2. Repository name: `aai-ji-store`
3. Make it "Public"
4. Click "Create repository"

### Step 3: Upload Your Files
1. Click "Add file" → "Upload files"
2. Drag and drop ALL your project files:
   - store.html
   - admin-dashboard.html
   - store.js
   - admin-dashboard.js
   - store.css
   - admin-dashboard.css
   - styles.css
   - admin.css
   - script.js
   - admin.js
   - index.html
   - admin.html
   - README.md

### Step 4: Enable GitHub Pages
1. Go to repository "Settings"
2. Scroll down to "Pages"
3. Source: Deploy from a branch
4. Branch: main
5. Folder: / (root)
6. Click "Save"

### Step 5: Your Store is Live! 🎉
Your permanent URLs will be:
- **Customer Store**: https://[your-username].github.io/aai-ji-store/store.html
- **Admin Panel**: https://[your-username].github.io/aai-ji-store/admin-dashboard.html
