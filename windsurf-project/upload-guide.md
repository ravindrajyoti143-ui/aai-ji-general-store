## 🚀 **Upload Steps:**

### **Step 1: Go to Repository**
1. **Visit:** https://github.com/ravindrajyoti143-ui/aaijiminimart
2. **Click "Add file"** (green button)
3. **Select "Upload files"**

### **Step 2: Upload Files**
1. **Drag and drop** ALL 12 files
2. **Or click "choose your files"**
3. **Select all files** from your project folder
4. **Add commit message:** "Add complete Aai Ji Mini Mart store"
5. **Click "Commit changes"**

### **Step 3: Enable GitHub Pages**
1. **Go to Settings → Pages**
2. **Source:** "Deploy from a branch"
3. **Branch:** "main"
4. **Folder:** "/ (root)"
5. **Click "Save"**

## ⚠️ **Important Notes:**

### **File Names:**
- Use **exact lowercase** names
- No spaces in filenames
- Use hyphens (-) not underscores (_)
- Correct extensions (.html, .js, .css)

### **Upload Order:**
1. Upload ALL files first
2. Then enable GitHub Pages
3. Wait 2 minutes for deployment

### **Troubleshooting:**
- If 404 persists, check file names
- Ensure all files are uploaded
- Verify GitHub Pages is enabled
- Wait full 2 minutes for deployment
