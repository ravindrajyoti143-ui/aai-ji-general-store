# 🚀 Quick Start - Make Your Store Permanent

## 📱 Easiest Way: GitHub Pages (5 Minutes)

### Step 1: Create GitHub Account
1. Go to **https://github.com**
2. Click **"Sign up"**
3. Fill details (free)
4. Verify email

### Step 2: Create Repository
1. Click **"New"** (green button)
2. Repository name: **`aai-ji-store`**
3. ✅ Make it **Public**
4. Click **"Create repository"**

### Step 3: Upload Your Files
1. Click **"Add file"** → **"Upload files"**
2. **Drag ALL files** from your project folder:
   ```
   📁 Your Project Folder
   ├── 📄 store.html
   ├── 📄 admin-dashboard.html
   ├── 📄 store.js
   ├── 📄 admin-dashboard.js
   ├── 📄 store.css
   ├── 📄 admin-dashboard.css
   ├── 📄 styles.css
   ├── 📄 admin.css
   ├── 📄 script.js
   ├── 📄 admin.js
   ├── 📄 index.html
   ├── 📄 admin.html
   └── 📄 README.md
   ```
3. Click **"Commit changes"**

### Step 4: Enable GitHub Pages
1. Click **"Settings"** (top menu)
2. Scroll down to **"Pages"**
3. Source: **"Deploy from a branch"**
4. Branch: **"main"** → **"/ (root)"**
5. Click **"Save"**

### Step 5: Your Store is LIVE! 🎉

**Your Permanent URLs:**
- 🛍️ **Customer Store**: `https://[your-username].github.io/aai-ji-store/store.html`
- 👨‍💼 **Admin Panel**: `https://[your-username].github.io/aai-ji-store/admin-dashboard.html`
